## 🎯 Quick Start

### How Skills Work

Skills are automatically loaded when you work on tasks that match their descriptions. You can also explicitly reference them in your requests.

### Example Usage

```
"Build a Next.js app with Stripe payments"
→ Activates: web-development, payment-integration

"Create a Telegram bot with AI features"
→ Activates: telegram-bots, ai-ml-integration

"Optimize my app's performance"
→ Activates: performance-optimization

"Set up CI/CD and deploy to production"
→ Activates: devops-deployment
```

## 📈 Best Practices

### Development Workflow
1. **Plan** - Design architecture, choose tech stack
2. **Develop** - Write code following best practices
3. **Test** - Unit, integration, E2E tests
4. **Optimize** - Performance, bundle size, queries
5. **Secure** - Security review, vulnerability scan
6. **Deploy** - CI/CD, monitoring, scaling

### Code Quality
- TypeScript for type safety
- ESLint + Prettier for consistency
- 80%+ test coverage
- Performance budgets
- Security audits

### Performance Targets (2026)
- LCP < 2.5s
- INP < 200ms
- CLS < 0.1
- Lighthouse score > 90
