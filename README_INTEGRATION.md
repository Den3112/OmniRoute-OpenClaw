## 💡 Как это работает

### Архитектура

```
┌─────────────────────────────────────────────────────────────┐
│                    OpenCode Agent                            │
│              (автоматическое сохранение)                     │
└────────────────────────┬────────────────────────────────────┘
                         │ MCP Protocol (stdio)
                         ▼
┌─────────────────────────────────────────────────────────────┐
│              OmniRoute MCP Server                            │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  Memory Tools:                                       │   │
│  │  • omniroute_memory_search   (поиск)               │   │
│  │  • omniroute_memory_add      (добавить)            │   │
│  │  • omniroute_memory_clear    (очистить)            │   │
│  └──────────────────────────────────────────────────────┘   │
└────────────────────────┬────────────────────────────────────┘
                         │ HTTP API
                         ▼
┌─────────────────────────────────────────────────────────────┐
│              OmniRoute Memory System                         │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  SQLite Database (storage.sqlite)                    │   │
│  │  • memories table (4 типа памяти)                   │   │
│  │  • FTS5 полнотекстовый поиск                        │   │
│  │  • 3 стратегии: exact, semantic, hybrid             │   │
│  └──────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

### Типы памяти

1. **factual** - факты о проекте, пользователе, технологиях
2. **episodic** - события и действия
3. **procedural** - инструкции и процессы
4. **semantic** - концепции и определения

### Стратегии поиска

1. **exact** - хронологический порядок
2. **semantic** - FTS5 полнотекстовый поиск
3. **hybrid** - комбинированный (рекомендуется) ⭐

## 🔧 Управление памятью

```
http://localhost:20128/dashboard/memory
```

Здесь можно:
- Просмотреть все воспоминания
- Фильтровать по типу
- Искать по содержимому
- Удалять записи

### Через API

```bash
# Список воспоминаний
curl http://localhost:20128/api/memory

# Создать воспоминание
curl -X POST http://localhost:20128/api/memory \
  -H "Content-Type: application/json" \
  -d '{
    "type": "factual",
    "key": "project_name",
    "content": "Проект называется free-ai-aggregator"
  }'

# Поиск
curl "http://localhost:20128/api/memory?query=проект"
```

### Через базу данных

```bash
# Просмотр всех воспоминаний

const memories = db.prepare('SELECT * FROM memories ORDER BY created_at DESC LIMIT 10').all();
console.log(JSON.stringify(memories, null, 2));
"
```
